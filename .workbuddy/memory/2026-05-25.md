## W键没反应 - 调试与修复（02:00）

**症状**：游戏可以运行，但按 W 键油门没有变化

**根因排查**：
1. `flight_test.tscn` 用的是旧的 `input_handler.gd`，而不是新的 `input_manager.gd`（两者都支持 W 键）
2. `input_handler.gd` 中 `plane = get_parent() as RigidBody3D` 逻辑正确，父节点绑定没问题
3. **真正的问题**：
   - `flight_model.gd` 的 `_ready` 里 `current_fuel` 赋值在 `mass = config.mass + current_fuel` 之后，导致质量少算了 36000kg 燃油
   - `md_11.tres` 的 `max_thrust = 80000 N`，真实推力约 800000 N（三台 267kN 发动机），推力远小于巡航阻力（~296000N），飞机出生后持续减速失速
   - 初始 `throttle = 0.0` + 油门速率 0.5/s，2 秒才能满油，期间已经开始失速

**修复内容**：
- `flight_model.gd`：`current_fuel` 赋值移到 `mass` 计算之前；`start_airborne` 时初始 `throttle = 0.6`
- `resources/aircraft/md_11.tres`：`max_thrust = 80000` → `800000`（正确的三发总推力）
- `scripts/input_handler.gd`：油门增速 `0.5/s` → `1.0/s`（W 按 1 秒可到满油）

## 按W无反应 - 字典访问语法错误修复（02:06）
##
**症状**：飞机垂直下落，按 W 完全没反应（上一轮修复推力数值后依旧）
##
**根因**：所有策略文件（`large_airliner_dynamics.gd` /
`medium_airliner_dynamics.gd` / `fighter_dynamics.gd`）中，
用 `state.xxx` 访问 Dictionary 键值 —— Godot 4 的 GDScript
虽然支持 `dict.key` 语法糖，但实际运行中 `state.throttle_input`
等表达式**静默返回 `0`/`null`**，导致：
- `target_thrust` 永远为 0 → 推力不变化
- `CL_approx` 基于 `state.alpha`（=0）→ 升力极低
- 飞机持续失速坠落
##
**修复内容**：三个策略文件共 ~60 处 `state.xxx` 全部改为
`state["xxx"]`（标准 Dictionary 访问语法）：
- `state.airspeed` → `state["airspeed"]`
- `state.alpha` → `state["alpha"]`
- `state.throttle_input` → `state["throttle_input"]`
- `state.pitch_input` → `state["pitch_input"]`
- `state.roll_input` → `state["roll_input"]`
- `state.yaw_input` → `state["yaw_input"]`
- `state.flap_position` → `state["flap_position"]`
- `state.gear_down` → `state["gear_down"]`
- `state.ground_clearance` → `state["ground_clearance"]`
- `state.dynamic_pressure` → `state["dynamic_pressure"]`
- `state.velocity` → `state["velocity"]`
- `state.forward` → `state["forward"]`
- `state.up` → `state["up"]`
- `state.angular_velocity_local` → `state["angular_velocity_local"]`
- `state.trim_elevator` → `state["trim_elevator"]`
